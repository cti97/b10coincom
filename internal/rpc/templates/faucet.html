What to run

Claiming means solving the Argon2id puzzle on your own machine and signing with the key that will receive the coins, so the command runs locally:

{{.Command}}

Replace <path> with the key file b10coin keygen --out wrote, and run it from a terminal on the machine that holds the key. It prints the transaction and asks you to confirm before it signs.

That command works against this node whatever chain it runs — {{.ChainID}} here, not only the devnet: the claim signs over the genesis hash the node reports (see /status's genesis_hash), and the amount it pays is the chain's own parameter, the {{.ClaimAmountB10}} b10 above. There is no devnet-only condition to meet.

One thing this page cannot check for you: a node whose key holds no committee seat accepts a claim and never proposes a block that carries it — a transaction reaches a block only through the node it was posted to. The claim command prints a warning when the node it reached says it holds no seat; in that case post the same bytes to a validator that does.

What this page cannot do

  • It cannot sign a transaction. Signing happens in b10coin claim on your machine, after you read the transaction it prints.
  • It cannot hold your key. Never paste a private key into a page: this page is served over plain HTTP, it has no use for a key, and a key pasted here would be a key exposed. Paste the address, never the key.
  • It cannot pay you. A claim is queued when the node accepts it and is paid only when a later block applies it; the coins are not spendable at the moment the claim is accepted.
  • The faucet is rate-limited: it pays one claim per key per epoch, and that is a consensus rule rather than a setting on this page. Claiming twice in one epoch is refused by the chain.
  • It cannot guarantee payment. Eligibility is the claim rule; the block that applies your claim also needs the faucet to hold the amount at that moment, and a claim whose block cannot pay it is dropped rather than held.
  • It cannot solve the Argon2id puzzle for you. Solving for anonymous requests would make this node's CPU the faucet's cost and turn it into a free-claim oracle, which is the whole reason the puzzle exists.
  • It cannot show history, search the chain or recover a lost key; it reports one address at the current head.
  • It is unauthenticated. The --http default binds the server to 127.0.0.1, but that is the operator's choice, not a property of this page: a node started with --http 0.0.0.0:8645 serves this page — and the node's transaction endpoint — to every network that can reach that port.
