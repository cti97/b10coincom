# Process note: how this tree was reviewed and merged

Written 2026-10-31, audit round five, so a future reader does not infer a review
process that did not happen. This note changes no history; it records it.

## The merge path

- **PR 17** (`M5: staking, stake-derived committee rotation, PEER_EXCHANGE, and
  the Nakamoto coefficient`) contains **42 commits and 19,566 insertions**. It
  was **merged by its author** (`cti97`). GitHub reports **no review decision**
  (`reviewDecision` empty): there was no approving review, no reviewer, and no
  review request.
- **PR 18** (`M5 plan`) contains **5 commits and 2,992 insertions**. It was
  merged the same way, by the same author, with no review.
- Every feature commit on this branch went **directly to `m5-plan`**. There was
  no feature branch, no per-commit review, and no second pair of eyes at any
  point. The milestone audits (`docs/audit-*.md`) are the only independent
  reading of the result, and they review the tree *after* it was merged.

This is a solo operator's repository (see `AGENTS.md`: one human, no review
team), so self-merging is the expected mechanics, not a concealed defect. The
defect would be **claiming review that did not happen**, and no document here
does.

## One commit's title does not describe its contents

Commit **`9653248`** is titled `test: compare the middle node's learned set
sorted, as learnedAddrs returns it`, but it also carries the **PX-2, PX-3 and
PX-4 feature fixes** (gated nonce-bound learned dials, the challenge-response
relay gate, dedup before verification). The next commit, **`0a655ba`**, admits
this in its own message. The commit was not split or rewritten; this note is the
correction, and the code and tests are the authority on what shipped.

## What stands in for review

Independent review did not. What did:

- a test suite that runs on every push (`.github/workflows/ci.yml`: plain,
  `-race`, vet, cross-vet on six targets, the acceptance commands);
- mutation testing recorded in the plans (a mutant must compile and a pinned
  test must fail);
- five audit rounds (`docs/audit-2026-10-04.md` through
  `docs/audit-2026-10-31-main.md`) that re-read the tree after merging, plus the
  Docker runs in `docs/testrun-*.md`;
- this round's fixes, each with the test or documented reason named in the
  audit response.

That is weaker than an independent reviewer on a protocol that handles value.
It is what the evidence is; do not upgrade it in prose.

## Two operational gaps this note records

- **Signing has never been executed** in this repository. Every `SHA256SUMS`
  produced here is UNSIGNED; the signing path is documented and gated on an
  operator-supplied key, but no run has used one.
- **The scheduled-failure reporter had never run** except as `skipped` until
  this round added a manual rehearsal: `gh workflow run ci.yml -f
  simulate_failure=true` fails the `test` job on purpose, runs the `report` job,
  and files one test issue. Delete that issue afterwards.
