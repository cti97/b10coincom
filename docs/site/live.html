Chain parameters

Fixture committee: every validator key is derived from a public seed, so anyone with the repository can sign as any seat. This chain carries no value — it is a plumbing testnet. Consensus has a known residual: a round divergence can pause block production for minutes before the timeout ladder closes it.
Data comes from a live validator seat behind NAT, pushed to this host every ~15 s. Relay counters are read from the relay's own journal once a minute. Source: cti97/b10coincom.
